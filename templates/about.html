About the project

A local computer-vision application combining a custom CNN with OpenCV Haar Cascade face detection.

Detection pipeline

  1. Read an uploaded image or browser camera frame.
  2. Locate faces with OpenCV Haar Cascade.
  3. Resize each face to 128 × 128 pixels.
  4. Normalize pixels and run CNN inference.
  5. Draw a label and confidence on the output.
